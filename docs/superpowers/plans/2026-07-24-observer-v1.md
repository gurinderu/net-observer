# observer v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A headless macOS root daemon that collects `link` + `proxy` network telemetry into DuckDB and fires passive incident triggers (wedge / gw-drop / gw-change pcap-freeze).

**Architecture:** Collectors (one tokio task per subsystem) emit typed `Sample`s onto an mpsc stream; a `StoreWriter` batches them into DuckDB and a `TriggerEngine` evaluates hot rules on a small in-memory recent window and invokes passive handlers. Platform I/O (ICMP, TCP-bind, DHCP/ARP/Wi-Fi, Clash API, tcpdump) sits behind traits so all logic is unit-tested with fakes; the real macOS adapters are thin and verified manually.

**Tech Stack:** Rust (edition 2024), tokio, DuckDB (`duckdb` crate), figment, jiff (time), hickory-resolver (later), surge-ping, socket2, reqwest (rustls), clap, thiserror/anyhow, tracing. Nix flake + direnv, structured like `~/projects/fluencelabs/lightmare`.

## Global Constraints

- **Maximize Rust:** pure-Rust crates everywhere a viable one exists. Only accepted native deps: **DuckDB** (C++) and, v1-only, the **`tcpdump` child** in `pcap-ring`.
- **v1 = observation + detection only.** No acting: no `launchctl kickstart`, no watchdog, no notification channel.
- **Rust edition:** `2024`. Toolchain pinned via `rust-toolchain.toml` channel `1.91.1` (matches lightmare).
- **Storage behind `Store` trait.** DuckDB is the only backend; big blobs (pcap, `log show`) are files on disk, only `blob_ref` metadata rows in the DB.
- **Timestamps:** stored as `ts_us BIGINT` = epoch microseconds. Forensics SQL wraps with `make_timestamp(ts_us)` for `ASOF JOIN` / `time_bucket`.
- **Verdict vocabulary (verbatim):** DNS `OK / FAKEIP / EMPTY / SERVFAIL / NXDOMAIN / TIMEOUT / SKIP`; gateway `OK / FAIL / NOGW`. A probe that cannot run emits `SKIP`, never silence.
- **Error style:** `thiserror` in crates, `anyhow` in bins. One collector failing must never take down the others.
- **Layout:** cargo workspace, `bin/` for binaries, `crates/` for libraries. `AGENTS.md` with `CLAUDE.md` symlink; `ARCHITECTURE.md`; CI under `.github/workflows`.
- Spec: `docs/superpowers/specs/2026-07-24-observer-net-collector-design.md`.

```rust
macro_rules! token_enum {
    ($name:ident { $($variant:ident => $token:literal),+ $(,)? }) => {
        #[derive(Debug, Clone, Copy, PartialEq, Eq, serde::Serialize, serde::Deserialize)]
        pub enum $name { $($variant),+ }
        impl fmt::Display for $name {
            fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
                f.write_str(match self { $(Self::$variant => $token),+ })
            }
        }
        impl FromStr for $name {
            type Err = ParseVerdictError;
            fn from_str(s: &str) -> Result<Self, Self::Err> {
                match s { $($token => Ok(Self::$variant),)+ _ => Err(ParseVerdictError(s.to_string())) }
            }
        }
    };
}

pub struct ParseVerdictError(pub String);
```

`duckdb_store.rs` (uses a `Mutex<Connection>` — DuckDB is single-writer):
```rust
use std::sync::Mutex;
use duckdb::{params, Connection};
use types::{BlobRef, Incident, Sample, TriggerFired};
use crate::{schema::SCHEMA_SQL, Store};

#[derive(Debug, thiserror::Error)]
#[error(transparent)]
pub struct StoreError(#[from] pub duckdb::Error);

pub struct DuckdbStore { conn: Mutex<Connection> }

impl DuckdbStore {
    pub fn in_memory() -> Result<Self, StoreError> { Self::from_conn(Connection::open_in_memory()?) }
    pub fn open(path: &str) -> Result<Self, StoreError> { Self::from_conn(Connection::open(path)?) }
    fn from_conn(conn: Connection) -> Result<Self, StoreError> {
        conn.execute_batch(SCHEMA_SQL)?;
        Ok(Self { conn: Mutex::new(conn) })
    }
}

impl Store for DuckdbStore {
    fn write_sample(&self, s: &Sample) -> Result<(), StoreError> {
        let c = self.conn.lock().unwrap();
        match s {
            Sample::Link(l) => c.execute(
                "INSERT INTO link_sample VALUES (?,?,?,?,?,?,?,?,?,?)",
                params![l.ts_us, l.gw.to_string(), l.gw_rtt_ms, l.direct.to_string(),
                    l.direct_rtt_ms, l.dhcp_router, l.dhcp_dns, l.gw_arp_mac, l.ssid, l.wifi_capture_present])?,
            Sample::Proxy(p) => c.execute(
                "INSERT INTO proxy_sample VALUES (?,?,?,?,?,?)",
                params![p.ts_us, p.server_ip, p.tcp.to_string(), p.rtt_ms, p.tun_code, p.selector])?,
        };
        Ok(())
    }
    fn open_incident(&self, i: &Incident) -> Result<(), StoreError> {
        self.conn.lock().unwrap().execute("INSERT INTO incident VALUES (?,?,?,?,?)",
            params![i.id, i.opened_us, i.closed_us, i.trigger_id, i.signature])?;
        Ok(())
    }
    fn close_incident(&self, id: &str, closed_us: i64) -> Result<(), StoreError> {
        self.conn.lock().unwrap().execute("UPDATE incident SET closed_us=? WHERE id=?", params![closed_us, id])?;
        Ok(())
    }
    fn write_blob_ref(&self, b: &BlobRef) -> Result<(), StoreError> {
        self.conn.lock().unwrap().execute("INSERT INTO blob_ref VALUES (?,?,?,?,?)",
            params![b.id, b.incident_id, b.ts_us, b.kind, b.path])?;
        Ok(())
    }
    fn write_trigger_fired(&self, t: &TriggerFired) -> Result<(), StoreError> {
        self.conn.lock().unwrap().execute("INSERT INTO trigger_fired VALUES (?,?,?,?)",
            params![t.ts_us, t.trigger_id, t.incident_id, t.detail])?;
        Ok(())
    }
```

```rust
pub struct Fire { pub detail: String }

        let links = w.recent_link(self.consecutive);

    }
```
